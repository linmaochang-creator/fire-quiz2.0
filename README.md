# 防火安全互動搶答

民眾用手機掃描 QR code、選頭像、輸入暱稱就能加入。主持人按按鈕出題、公布答案，結束後公布排名。
題庫 30 題，每場從題庫隨機抽題（預設 10 題，可選 5～30 題），選項順序也會每場打亂。
只用 Node.js 內建功能，**不需要安裝任何套件，也不需要網際網路**（現場沒有外網也能用）。

## 一、第一次準備（只做一次）

1. 在主持人的電腦安裝 Node.js（到 nodejs.org 下載 LTS 版本；Windows 也可以用 PowerShell 執行 `winget install OpenJS.NodeJS.LTS`）。
2. 把整個 `fire-quiz` 資料夾放在電腦上任何位置。

## 二、活動當天

1. **電腦與民眾的手機必須連到同一個 Wi-Fi。** 現場沒有 Wi-Fi 時，可以用手機開「個人熱點」，電腦連上它，民眾也連同一個熱點。
2. 啟動：Windows 按兩下 `啟動.bat`；Mac／Linux 在資料夾裡執行 `node server.js`。
3. 黑色視窗會顯示「主持人頁面」的網址（含 PIN 碼），複製貼到瀏覽器開啟。畫面上會自動出現 QR code，投影給大家掃。
4. 第一次啟動時 Windows 可能跳出防火牆詢問，請選「允許存取」，否則手機連不上。

## 三、主持流程

| 畫面 | 主持人按 | 民眾手機 |
|---|---|---|
| 等待加入（可調整本場題數、作答時間） | 開始 | 選頭像、輸入暱稱，等待 |
| 作答中 | 公布答案 | 倒數圈、四色按鈕、點選即鎖定 |
| 公布答案 | 下一題 | 對錯、得分、名次升降、解析、前 5 名 |
| 最後一題公布後 | 公布最終排名 | 自己的名次、最長連對、前 10 名，前三名放彩帶 |
| 成績排名 | 再玩一次（保留玩家）／清空所有玩家 | |

- 鍵盤的 **空白鍵** 或 **→ 鍵** 等於按下主要按鈕，可以搭配簡報遙控器。
- 暱稱不適當：在等待畫面按名字旁的 ✕ 移除。
- 計分：答對 1000 分，越快答對最多再加 500 分；連續答對從第 2 題起每題多加 50 分，最多 +200。同分時比答對題數，再比答對的總耗時。
- 手機有音效（右上角 🔊 可關閉），Android 手機答題時會震動；iPhone 不支援網頁震動，只有音效。
- 手機重新整理或斷線後，會自動用原本的暱稱與頭像回到遊戲，不會掉分。
- 作答期間，正確答案與解析不會傳到任何一支手機或主持人畫面，要等公布後才送出。

## 四、修改題目

用記事本打開 `questions.json` 修改，存檔後重新啟動程式即可。

- `title`、`organizer`：畫面上方的活動名稱與單位。
- `defaultCount`：每場預設抽幾題。
- `answer`：正確選項的位置，**從 0 開始**（0 = 第一個選項，1 = 第二個，以此類推）。
- 每題 2～4 個選項，題數不限。每場開始時程式會隨機抽題並打亂選項，所以 `answer` 的位置不影響遊戲。
- 啟動時程式會檢查格式，有錯會直接告訴你是第幾題。

## 五、民眾不在同一個 Wi-Fi（例如戶外、用行動網路）

電腦的區域網路位址只有同一個網路裡的手機連得到。若民眾是用 4G／5G 掃碼，需要把這個資料夾放到一個有公開網址的主機（例如 Render、Railway、Fly.io 這類支援 Node.js 的服務），並設定環境變數：

- `PUBLIC_URL`：公開網址，例如 `https://xxx.onrender.com`（QR code 會用它）
- `HOST_PIN`：自己訂一組主持人 PIN 碼（不設的話每次啟動會隨機產生，要到主機的 log 查看）
- `PORT`：多數服務會自動提供，不用設

啟動指令是 `node server.js`，不需要 build。

## 六、檔案說明

- `server.js`：主機程式（抽題、計分、狀態同步、主持人權限）
- `questions.json`：題庫（30 題）
- `public/index.html`：民眾手機畫面
- `public/host.html`：主持人畫面
- `public/qr.js`：離線 QR code 產生器
- `public/manifest.webmanifest`、`public/icon.svg`：加到手機主畫面時使用的名稱與圖示

## 七、注意事項

- 暱稱匿名：主機只在記憶體中保存暱稱與成績，關掉程式就全部清除，不會寫入檔案。
- 主持人 PIN 只有開啟 `/host` 頁面的人需要，請不要把含 PIN 的網址投影在螢幕上（頁面載入後會自動把 PIN 從網址列移除）。
- 活動前請務必先用自己的手機完整測試一輪。
